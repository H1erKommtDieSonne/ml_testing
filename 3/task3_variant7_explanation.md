# Практическая работа 3. Многослойный персептрон. Вариант 7

## 1. Общий смысл программы

Цель работы — разобраться, как многослойный персептрон классифицирует точки и как на результат влияют функции активации, количество нейронов и количество слоёв. По таблице вариантов первая задача использует тип 7, вторая — типы 3, 5 и 6.

В первой задаче программа распознаёт точки внутри двух непересекающихся квадратов. Сначала веса рассчитываются вручную по геометрии, затем похожая сеть обучается на примерах. Во второй задаче программа классифицирует трёхмерные точки и сравнивает время и качество обучения сетей разных размеров.

Последовательность работы:

1. Создать ручной персептрон и двумерную выборку.
2. Проверить ручные коэффициенты с разными функциями активации и построить выходы всех нейронов.
3. Обучить 9 конфигураций сетей по 3 раза, сравнить precision и recall.
4. Визуализировать обученную сеть и отключить 25% и 50% нейронов её предпоследнего слоя.
5. Сгенерировать три типа трёхмерных данных и объединить их в два класса.
6. Обучить 10 сетей с увеличением первого скрытого слоя на 5 нейронов, построить графики времени и качества.
7. Дополнительно сравнить сети с одним, двумя и тремя скрытыми слоями.

Решение построено по образцу `task3_example.py`: функции активации, класс `ManualMLP`, матричный прямой проход, просмотр всех слоёв, генерация случайных точек, `train_test_split`, `MLPClassifier`, `classification_report`, повторные эксперименты и тепловые карты. Из примера не перенесены неиспользуемые импорты. Исправлены независимые диапазоны сетки x/y и подписи осей тепловых карт. Графики сохраняются в файлы, чтобы весь эксперимент прошёл без необходимости закрывать окна.

Основная теория взята из лекции 5: формальный нейрон, построение областей слоями, ручные коэффициенты, обратное распространение ошибки, влияние активации и инициализации. Определения precision/recall и сравнение обучения с тестом соответствуют материалам лекций 2, 3 и 6. Из остальных лекций дополнительные алгоритмы для этой работы не требуются.

## 3. Задание 2: геометрия и ручная сеть

### 3.1. Выбранные квадраты

Обозначим класс 1 через C:

```text
Q1: -3 < x < -1, -1 < y < 1
Q2:  1 < x <  3, -1 < y < 1
C = Q1 ∪ Q2
```

Оба квадрата имеют сторону 2 и не пересекаются. Границы относятся к классу 0, поскольку в задании указаны точки внутри квадратов. Выборка равномерная в прямоугольнике [-4,4] × [-2,2]. Она содержит внутренности квадратов, промежуток между ними и окружение. Ожидаемая доля класса 1 равна 8/32 = 25%.

Одной прямой классы разделить нельзя: объединение квадратов невыпукло. Для точного воспроизведения их границ нужны шесть различных прямых:

```text
x = -3, x = -1, x = 1, x = 3, y = -1, y = 1.
```

Не восемь: верхние и нижние стороны квадратов лежат на общих прямых. Меньше шести прямых в таком построении недостаточно: каждая из шести прямых содержит непустой отрезок границы классов, и другую прямую нельзя совместить со всем этим отрезком.

Класс 1 состоит из двух связных выпуклых компонент — двух квадратов. Класс 0 связен, но невыпуклый. Его можно покрыть пятью связными выпуклыми областями:

```text
R1: x <= -3
R2: -1 <= x <= 1
R3: x >= 3
R4: y <= -1
R5: y >= 1
```

Эти области могут перекрываться. Это допустимо: на выходе выполняется логическое ИЛИ. Если нужно неперекрывающееся разбиение, верхнюю и нижнюю области можно ограничить -3 < x < 3, а среднюю — дополнительно -1 < y < 1. Для реализации сети удобнее приведённое покрытие. Важно различать пять выпуклых частей покрытия и число связных компонент внешнего класса: связная компонента у него одна.

### 3.2. Число слоёв и нейронов

По схеме лекции «прямые → выпуклые области → классы» достаточно структуры:

```text
2 входа → 6 нейронов → 7 нейронов → 2 выхода.
```

Входы — координаты x, y; первый скрытый слой проверяет шесть полуплоскостей; второй выделяет два квадрата и пять внешних областей; выходной слой объединяет области каждого класса. Всего два скрытых слоя, три слоя нейронов с весами и 15 вычисляющих нейронов.

Это достаточная оценка по конструкции преподавателя, а не утверждение об абсолютном минимуме среди всех возможных нейросетей. Если распознавать только класс 1, второй скрытый слой можно сократить до двух нейронов квадратов, а выход — до одного: 2 → 6 → 2 → 1. Класс 0 тогда определяется отрицанием результата. Такая компактная реализация не показывает отдельно пять внешних областей. В программе используется развёрнутый вариант для прямой аналогии с лекционным примером, а размеры соседних сетей сравниваются относительно (6,7).

### 3.3. Коэффициенты первого слоя

Пусть S(t)=1 при t>0 и S(t)=0 иначе. Каждый нейрон вычисляет S(w_x x + w_y y + b):

| Нейрон | Формула | Условие срабатывания |
|---|---|---|
| h1 | S(x+3) | x > -3 |
| h2 | S(-x-1) | x < -1 |
| h3 | S(x-1) | x > 1 |
| h4 | S(-x+3) | x < 3 |
| h5 | S(y+1) | y > -1 |
| h6 | S(-y+1) | y < 1 |

В `layer1_c` строки соответствуют входам x,y, а столбцы — нейронам. Поэтому матрица имеет размер 2×6. Вектор `layer1_i` имеет длину 6. Для N точек умножение (N×2)·(2×6) даёт N×6 взвешенных сумм.

### 3.4. Коэффициенты второго слоя

```text
g1 = S(h1 + h2 + h5 + h6 - 3.5)  — левый квадрат
g2 = S(h3 + h4 + h5 + h6 - 3.5)  — правый квадрат
g3 = S(-h1 + 0.5)                 — x <= -3
g4 = S(-h2 - h3 + 0.5)            — -1 <= x <= 1
g5 = S(-h4 + 0.5)                 — x >= 3
g6 = S(-h5 + 0.5)                 — y <= -1
g7 = S(-h6 + 0.5)                 — y >= 1
```

Внутри квадрата все четыре нужных входа равны 1: сумма 4 больше 3.5. Если нарушается хотя бы одно условие, сумма не больше 3 и нейрон не срабатывает. Порог 0.5 позволяет реализовать отрицание: S(-h+0.5)=1 ровно при h=0. У среднего промежутка нужны одновременно h2=0 и h3=0. Матрица второго слоя имеет размер 6×7.

### 3.5. Выходной слой

```text
u1 = S(g1 + g2 - 0.5)
u0 = S(g3 + g4 + g5 + g6 + g7 - 0.5)
```

Первый выход отвечает классу 1, второй — классу 0. При пороговой активации получаем (1,0) внутри квадратов и (0,1) снаружи. Матрица третьего слоя имеет размер 7×2. После смены активации выходы уже не обязаны быть такими парами, поэтому программа выбирает класс 1 при u1>u0. При равенстве выбирается класс 0.

### 3.6. Изменение активации и обучение

Ручные веса проверяются с S(t), сигмоидой 1/(1+exp(-10t)), обычной сигмоидой 1/(1+exp(-t)) и ReLU=max(0,t). Веса при этом не меняются. Логические правила второго слоя рассчитаны для нулей и единиц, поэтому после замены активации точное геометрическое решение может исчезнуть. Крутая сигмоида ближе к ступеньке; обычная сильнее сглаживает границы. ReLU не ограничена единицей, поэтому полученные для логических операций пороги могут перестать работать.

Обучаемая сеть начинает со случайных коэффициентов. `fit` меняет их по ошибке предсказаний с помощью обратного распространения ошибки; оптимизатор по умолчанию — Adam. В отличие от ручного расчёта, обучение не гарантирует нахождение точного решения. Сравниваются скрытые слои (5,6), (5,7), (5,8), (6,6), (6,7), (6,8), (7,6), (7,7), (7,8); для каждого выполняются три запуска.

У `MLPClassifier` при бинарных целочисленных метках выходной нейрон один: он оценивает вероятность класса 1. Выходная активация — сигмоида. Поэтому нельзя ожидать полного совпадения его матриц с ручной сетью с двумя выходами. Сравниваются качество классификации и внутренние представления, а не равенство коэффициентов. Для просмотра обученных слоёв её веса передаются в `ManualMLP` с обычной сигмоидой.

### 3.7. Отключение нейронов

Заранее выбрана архитектура (6,8), чтобы 25% и 50% второго скрытого слоя означали ровно 2 и 4 нейрона. Из трёх повторов выбирается сеть с лучшим F1 на обучающей выборке, без выбора по тестовым метрикам. F1=2PR/(P+R) учитывает обе метрики; малая добавка в знаменатель предотвращает деление на ноль.

Каждый раз создаётся новая копия исходной сети и отключаются первые 0, 2 или 4 нейрона. Зануляются входящие веса, смещения и исходящие связи. Последнее важно: сигмоида от нуля равна 0.5, поэтому только обнуление входов не устраняет вклад нейрона. Дообучения после отключения нет. Снижение качества показывает важность удалённых связей; сохранение качества говорит о возможной избыточности именно этой части сети. Один фиксированный набор отключённых нейронов не доказывает избыточность или необходимость каждого нейрона всей модели.

## 4. Задание 3: трёхмерная выборка

Выбраны множества:

```text
Тип 3: 0 < x < 1, |y| < 0.5, |z| < 0.5.
Тип 5: x - y + z < -3.
Тип 6: -1 < 0.2x + 0.2y + z < 1.
```

Типы 3 и 5 объединены в класс 1, тип 6 — в класс 0. Исходные множества пересекаются: весь куб лежит внутри полосы типа 6, поскольку на кубе -0.6 < 0.2x+0.2y+z < 0.8. Часть типа 5 тоже пересекается с полосой. Если независимо генерировать точки на всех трёх множествах с разными метками, одна и та же область будет содержать противоречащие классы.

В задании разрешено выбирать распределения произвольно. Поэтому для класса 0 используется условное распределение на части типа 6 вне куба и вне полупространства типа 5. Все оставшиеся точки по-прежнему удовлетворяют условию типа 6. Это явный выбор распределения, а не предположение, будто исходные множества не пересекаются.

Куб содержит 1500 равномерных точек. Для типа 5 координаты x,y равномерны в [-3,3], а z=-3-x+y-d, где d равномерно распределено от 0.1 до 2. Для типа 6 берутся x,y в [-3,3] и z=t-0.2x-0.2y с t в [-1,1], затем исключаются пересечения с классом 1. Набираются 3000 допустимых точек типа 6. Итого 6000 точек, поровну обоих классов; обучение — 4800, тест — 1200.

Объединение куба с полупространством требует более сложного разделения, чем одна плоскость. Начальная архитектура (10,8) выбрана как практическая отправная точка: первый слой может представить несколько граничных плоскостей, второй — сочетать признаки областей. Это не доказательство минимального размера. Для обучения выбрана ReLU.

Основной эксперимент сравнивает (10,8), (15,8), …, (55,8), всего 10 сетей. Второй слой, данные, разбиение, активация, случайное состояние и настройки остановки одинаковы. Измеряется время вызова `fit`, число эпох `n_iter_` и отношение времени к числу эпох. Последнее — среднее время эпохи с накладными расходами `fit`, а не отдельный хронометраж каждой эпохи. Полное время не обязано монотонно расти: более широкая сеть иногда требует меньше эпох.

Дополнительный эксперимент (20,), (20,8), (20,8,8) проверяет влияние глубины. Он отделён от обязательных десяти сетей. Замеры каждого размера выполняются один раз, поэтому небольшие различия времени не следует трактовать как строгую закономерность.

## 5. Как читать метрики

Все precision и recall в работе рассчитаны для класса 1:

```text
TP — точка класса 1 правильно отнесена к классу 1;
FP — точка класса 0 ошибочно отнесена к классу 1;
FN — точка класса 1 ошибочно отнесена к классу 0;
precision = TP / (TP + FP);
recall = TP / (TP + FN).
```

Precision показывает, какая доля положительных ответов верна. Recall показывает, какую долю всех настоящих объектов класса 1 нашли. Если сеть всегда отвечает 0, recall=0, а неопределённый precision программа также записывает как 0. Если сеть всегда отвечает 1, recall=1, но precision равен доле положительного класса: для двумерной выборки около 0.25. Поэтому одна высокая полнота ещё не означает хорошую модель.

Переобучение оценивается сравнением обучения и теста: устойчиво более высокие обучающие метрики при ухудшении тестовых указывают на переобучение. Небольшой разрыв на одном разбиении сам по себе не доказывает его. Если обе выборки распознаются плохо, это скорее недостаточное обучение или неподходящая модель.

## 7. Ответы на контрольные вопросы

**1. Как оценить конфигурацию при линейно отделимой выборке?** Если два класса разделяются одной гиперплоскостью, достаточно одного выходного порогового нейрона с числом входов, равным числу признаков; скрытые слои не нужны. При двух явных выходах можно использовать два противоположных линейных решающих правила. Для более сложной геометрии можно сначала посчитать граничные прямые или плоскости, затем выпуклые области и их объединения.

**2. Как повлияло изменение функции активации?** На неизменных ручных весах пороговая функция дала точное решение, крутая сигмоида — близкое, обычная сигмоида и ReLU существенно ухудшили результат. Обучение с гладкой активацией подбирает новые веса и может вернуть высокое качество. Менять активацию на готовых весах и обучать сеть с другой активацией — разные эксперименты.

**3. Как повлияло увеличение числа нейронов?** Качество менялось немонотонно, поскольку важны не только размер сети, но и начальные веса и процесс оптимизации. В трёхмерной задаче рост ширины увеличил среднюю стоимость эпохи, но полное время зависело ещё и от количества эпох до остановки.

**4. Как проявляется переобучение?** Сеть хорошо распознаёт обучающие примеры, но хуже новые, то есть возникает существенный разрыв между обучением и тестом. Слишком подробное приспособление к обучающим точкам ухудшает способность обобщать. В проведённом трёхмерном эксперименте явного переобучения по сравнению precision/recall не обнаружено.
